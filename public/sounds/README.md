# Bildirim Sesleri

Bu dizine aşağıdaki MP3 dosyalarını ekle (Mixkit veya benzeri kaynaklardan):

| Dosya           | Kullanım                          |
|-----------------|-----------------------------------|
| `kritik.mp3`    | Kritik bildirimler (stok tükendi, kasa min) |
| `uyari.mp3`     | Uyarı bildirimleri (co-pilot büyük işlem)   |
| `bilgi.mp3`     | Bilgi ve başarı bildirimleri                |

Dosyalar yoksa `sesCal()` sessizce devam eder (graceful fallback).
